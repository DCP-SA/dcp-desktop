- G34 differentiated error states

- In-app log viewer

## Deferred to 0.4.0+ / structural

- Single-supervisor architecture decision (.exe-shim vs OS-supervised daemon)
- First-class `run_mode = scheduled / idle`
- Update channels (stable / beta / canary)
- E2E signed update bundles
- `pynvml` instead of `subprocess.run("nvidia-smi")`
- Cross-platform CI install matrix
